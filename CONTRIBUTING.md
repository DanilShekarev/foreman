# Как контрибьютить

Спасибо, что решили помочь. Коротко о том, как здесь всё устроено.

## Язык

Проект русскоязычный: интерфейс, комментарии в коде и сообщения коммитов —
по-русски. README продублирован на английском, i18n интерфейса — в планах.
Если вам удобнее писать по-английски — пишите, это не повод не прислать PR;
поправим вместе.

## Окружение

```bash
./start.sh        # Linux/macOS — создаст .venv и запустит сервер
start.bat         # Windows
```

Настройки — в `.env` (образец: `.env.example`). Для работы агента нужен либо
токен подписки Claude (`claude setup-token` → `auth_token.txt`), либо любой
OpenAI-совместимый API, настроенный в админке.

## Проверки

Тестов нет — проверка руками: запустить сервер и прокликать то, что меняли.
Обязательный минимум перед PR:

```bash
.venv/bin/python -m py_compile server.py store.py agent.py agent_openai.py agent_tools.py llm.py vaultlib.py gitops.py prompts.py docx_io.py common.py code_mirror.py transcribe_call.py
```

## Правила, которые не обсуждаются

Это продукт, в котором живут команды, — обновление не имеет права ломать
существующую установку:

- **Данные святы.** Миграции схемы — только догоняющие и идемпотентные
  (`store.init_db`); ничего не удаляем и не переписываем задним числом.
- **Безопасность.** У каждой новой HTTP-ручки — проверка авторизации и прав;
  секреты не логируются и наружу не отдаются; права агента на пути — только
  через `vaultlib` (единственный источник правил).
- **Один воркер uvicorn, без reload** — агент-сессии живут в процессе.
- **store.py не знает про FastAPI**; любая запись — внутри `store.write_tx()`.
- **Фронтенд без сборки и CDN** — сторонние библиотеки только вендорингом
  в `web/vendor/` (с записью в THIRD-PARTY.md); UI строится на токенах темы
  из `style.css`, цвета не хардкодятся.

Подробная архитектура — в [CLAUDE.md](CLAUDE.md): файл писался как контекст
для ИИ-агента, но это лучший обзор внутренностей и для человека.

## Pull request

Небольшие исправления присылайте сразу. Для заметных фич сначала откройте
issue и опишите замысел — обидно делать работу, которую не примут из-за
несовпадения взглядов.
