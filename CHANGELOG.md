# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/) (пока 0.x — API и схема
могут меняться). Каждое заметное изменение дописывается в «Не выпущено»
тем же коммитом, что и само изменение; при релизе раздел переезжает под
номер версии с датой.

## [Не выпущено]

### Добавлено
- Отправка изображений со сжатием или в оригинале — как в Telegram:
  при перетаскивании в чат появляются две зоны сброса («со сжатием» /
  «без сжатия»), при вставке из буфера и прикреплении скрепкой — окно
  предпросмотра с галочкой «Отправить без сжатия». Сжатие происходит в
  браузере: длинная сторона до 2560 px, перекодирование в JPEG (#106).

### Изменено
- Прочитанность честная: сообщение помечается прочитанным, только когда
  пользователь реально его видит — окно в фокусе, был ввод (мышь, клавиатура,
  колесо) за последнюю минуту и лента прокручена к низу. Открытый на фоне
  или без человека за компьютером чат сообщений не «читает»; отметка
  ставится при возвращении внимания. Закрытие окна звонка тоже помечает
  накопившееся (#105).
- Claude Agent SDK поднят до 0.2.168: вшитый в него CLI знает Opus 5.5 и
  Sonnet 5.5, алиасы `opus` и `sonnet` в реестре моделей теперь ведут на
  них. Существующей установке нужен
  `pip install -r requirements.txt` — `start.bat` ставит зависимости
  только при создании `.venv` (#112).

### Исправлено
- Агент читает длинные треды и расшифровки созвонов: `read_thread`
  отдаёт тред страницами по ~30 тыс. символов (аргумент `offset`). Раньше
  тред уходил одним куском, и Claude-движок откладывал слишком длинный
  результат во временный файл, недоступный агенту, — саммари созвона не
  получалось (#113).
- Ссылка-приглашение для уже авторизованного пользователя ведёт на главную
  вместо ошибки «ссылка недействительна» (#75).
- Загрузка файла в волт больше не перезаписывает существующий документ
  молча: при совпадении имени предлагается выбор «Заменить» (история правок
  сохраняется) или «Загрузить как копию» — копия получает суффикс `-2`,
  `-3`, … и, для docx, свою папку картинок (#36).
- Голые ссылки в сообщениях (`https://…` без markdown-разметки) стали
  кликабельными — в чатах, тредах, описаниях карточек и документах;
  хвостовая пунктуация («скобка, точка в конце») в адрес не попадает (#104).
- Тред открывался не с начала: панель тянула сообщения без `limit`, а
  серверный дефолт — 60, поэтому у длинного треда (например,
  расшифровки звонка на 86 реплик) начало было недостижимо (#101).
- Вики-ссылки с алиасом `[[Документ|текст]]` в чатах, волте и канбане
  показываются текстом алиаса и ведут на документ, а не рендерятся сырой
  строкой (#93).
- Волт: текст всегда пишется с LF-переносами (`newline="\n"`) — на Windows
  файлы больше не расходятся с `.gitattributes` (`eol=lf`) и git не держит
  их вечно «изменёнными» (#98).

### Добавлено
- История изменений доступна людям: страница «Изменения» на сайте
  (GitHub Pages, ссылки в навигации и футере лендинга) и окно «Что нового»
  в самом приложении — открывается кликом по логотипу Foreman в сайдбаре,
  показывает CHANGELOG.md установленной версии (#52).
- Шумоподавление в звонках: RNNoise (WebAssembly) в AudioWorklet плюс мягкий
  гейт по речевой вероятности — давит ровный фон (вентилятор, гул) и щелчки
  клавиатуры в паузах. По умолчанию выключено, включается тумблером
  «Шумоподавление» в поповере громкости прямо во время звонка; выбор
  запоминается. Пока выключено, ничего лишнего не грузится и задержки не
  добавляется. Обработка попадает и в запись дорожки, а значит в расшифровку.
  Не загрузился wasm — остаётся гейт по энергии, звонок работает как раньше
  (#102).
- Настройки громкости в звонке: свой микрофон (0–200%), каждый собеседник и
  звук демонстрации (0–100%) — кнопка громкости в панели звонка; значения
  запоминаются. Демонстрация экрана теперь захватывает и звук, если отметить
  галку в диалоге браузера (#99).
- Роли пользователей: команда заводит свои роли («программист», «ГД», …),
  у человека их может быть несколько. Назначают админ и модератор; встроенную
  роль «Модератор» раздаёт только админ. Роли видны в админке, в списке
  участников чата (клик по названию), в карточке человека (клик по имени
  в сообщении) и в контексте агента (#66).
- PWA: манифест, иконки и минимальный service worker — сайт ставится как
  приложение на телефон и десктоп (без offline-кэша: данные живые) (#62).
- Бэкапы: `tools/backup.py` (снимок базы, bundle волта, докопирование
  вложений и записей звонков, ротация) и автозапуск в сервере раз в
  `GD_BACKUP_HOURS` часов (по умолчанию 24).

## [0.1.0] — 2026-08-22

Первая публичная версия.

- Чаты: каналы, личные сообщения, треды, реакции, закрепы, упоминания,
  прочитанность, вложения, лента активности.
- База знаний («волт»): markdown под git, вики-ссылки и обратные ссылки,
  WYSIWYG-редактор (Toast UI) с откатом на CodeMirror/textarea, история и
  откат правок, импорт/экспорт Word.
- ИИ-агент: два движка — Claude Agent SDK (подписка) и любой
  OpenAI-совместимый API (реестр провайдеров в админке); права через
  path-гарды, каждый ход — git-коммит с diff и откатом.
- Зеркало кодовой базы: shallow/partial-клон любой git-ветки
  (`GD_CODE_REPO`/`GD_CODE_PATHS`), только чтение.
- Канбан-доска: колонки, drag & drop, чеклисты, приоритеты, метки,
  исполнители; доступна агенту.
- Созвоны: WebRTC-звонки с демонстрацией экрана, запись дорожек,
  расшифровка в тред внешним ASR-пайплайном (опционально).
- Установка: `start.sh` / `start.bat`, настройки в `.env`, документация
  README (en/ru), страница на GitHub Pages, CI (py_compile, Ubuntu+Windows).
