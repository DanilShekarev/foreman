# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/) (пока 0.x — API и схема
могут меняться). Каждое заметное изменение дописывается в «Не выпущено»
тем же коммитом, что и само изменение; при релизе раздел переезжает под
номер версии с датой.

## [Не выпущено]

## [0.1.0] — 2026-08-22

Первая публичная версия.

- Чаты: каналы, личные сообщения, треды, реакции, закрепы, упоминания,
  прочитанность, вложения, лента активности.
- База знаний («волт»): markdown под git, вики-ссылки и обратные ссылки,
  WYSIWYG-редактор (Toast UI) с откатом на CodeMirror/textarea, история и
  откат правок, импорт/экспорт Word.
- ИИ-агент: два движка — Claude Agent SDK (подписка) и любой
  OpenAI-совместимый API (реестр провайдеров в админке); права через
  path-гарды, каждый ход — git-коммит с diff и откатом.
- Зеркало кодовой базы: shallow/partial-клон любой git-ветки
  (`GD_CODE_REPO`/`GD_CODE_PATHS`), только чтение.
- Канбан-доска: колонки, drag & drop, чеклисты, приоритеты, метки,
  исполнители; доступна агенту.
- Созвоны: WebRTC-звонки с демонстрацией экрана, запись дорожек,
  расшифровка в тред внешним ASR-пайплайном (опционально).
- Установка: `start.sh` / `start.bat`, настройки в `.env`, документация
  README (en/ru), страница на GitHub Pages, CI (py_compile, Ubuntu+Windows).
