# Профиль проекта

Этот файл читает агент в начале каждого разговора — здесь он узнаёт, чем
занимается команда. Замените текст ниже на описание своего проекта: чем
конкретнее, тем точнее ответы. Файл правится прямо здесь, в веб-редакторе,
менять код для этого не нужно.

## О чём проект

Одним-двумя абзацами: что вы делаете, для кого, на каком этапе. Упомяните
термины, которые в команде считаются само собой разумеющимися, — агент их
ниоткуда больше не узнает.

> Пример: «Мобильная игра-головоломка про садовода. Игрок собирает поле из
> клеток-растений, каждое растение даёт эффект соседям. Ключевые сущности:
> грядка, сорт, сезон, заказ. Сейчас готовим софт-лонч.»

## Как устроена база знаний

Опишите структуру папок в `shared/` и договорённости команды: что где лежит,
какие документы обязательны, как называются.

> Пример: «`mechanics/` — по документу на механику, `economy/` — цифры и
> таблицы, `research/` — заметки с плейтестов. У каждого документа H1 и
> резюме в три строки сверху.»

## Договорённости

Всё, что агент должен соблюдать, но не может вывести сам: терминология,
запреты, стиль, кого спрашивать в спорных случаях.

> Пример: «Пишем "грядка", не "клетка". Цифры баланса берём только из кода,
> не из старых документов — они устарели. Не заводим задачи на доске без
> явной просьбы.»
