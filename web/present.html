Знания студии не должны жить в головах

Диздоки разбросаны по гуглодокам, ответы «как это на самом деле работает» ждут свободного программиста, а решения из чатов теряются за неделю.

Было
  • Диздоки в разных сервисах, версии — «финал_2_новый»
  • «Как работает пена?» — вопрос программисту и день ожидания
  • Правки документов не отследить: кто, что, когда
  • Обсуждения в мессенджере отдельно от документов
Стало
  • Один волт диздоков под git — каждая правка это коммит
  • Агент отвечает по исходникам игры за минуту, со ссылкой на файл
  • Diff любого изменения и откат одной кнопкой
  • Чаты, документы и агент — в одном окне, со сквозным поиском
Что внутри

Три продукта в одном

💬

Чаты команды

Каналы, личные сообщения, треды, реакции, закрепы, прочитанность — полноценный рабочий мессенджер уровня Slack, но внутри периметра студии.

📚

Волт диздоков

База знаний в markdown под git: вики-ссылки, обратные ссылки, история правок, редактор в браузере, импорт и экспорт Word-файлов.

🤖

ИИ-агент

Ведёт диздоки и отвечает, как механики реально устроены в коде игры. Каждый его ход — git-коммит с diff и кнопкой отката.

Чаты

Мессенджер, в котором ничего не теряется

Всё, к чему команда привыкла в Slack и Telegram, — и всё это связано с диздоками.

  • Треды и ответы — любую ветку ответов можно свернуть в тред одной кнопкой
  • Прочитанность — галочки ✓✓ и «кто прочитал и во сколько»
  • Скриншот из буфера — Ctrl+V, и картинка уже в чате
  • Документ из волта — прикрепляется ссылкой, открывается рядом
  • Поиск Ctrl+K — сразу по сообщениям и документам
  • Реакции, закрепы, упоминания, черновики, «кто печатает», уведомления

Код игры

«Как это работает?» — ответ за минуту, а не за день

Агент читает исходники Unity-проекта и переводит их на язык геймдизайна.

  • Пишет для дизайнеров — без имён классов и сетевых деталей, только суть и цифры
  • Всегда указывает источник — одна строка с путём к файлу
  • Читает зеркало ветки main — не мешает программистам и не видит их недоделанных правок
  • Начинает с карты проекта — не бродит по репозиторию вслепую
  • Только чтение — изменить код игры агент не может физически

Волт

База диздоков, у которой есть память

Каждое сохранение — git-коммит с автором. История любого документа, diff любой правки, откат чего угодно.

  • Вики-ссылки — документы ссылаются друг на друга через [[название]], снизу видно, кто ссылается на этот док
  • Редактор в браузере — подсветка markdown, Ctrl+S, защита от затирания чужих правок
  • Word туда и обратно — импорт .docx с картинками, экспорт любого дока в .docx
  • Права — общая база для всех, личные папки видит только владелец
  • Поиск — по названиям и тексту, вместе с сообщениями чатов

Контроль

ИИ на коротком поводке

Агент полезен ровно настолько, насколько ему можно доверять. Поэтому каждое его действие ограничено технически, а не «честным словом».

🚫

Без доступа к системе

Выполнять команды агент не может вообще: shell запрещён целиком, git-коммиты делает сам сервер.

✅

Белый список инструментов

Разрешено только чтение, поиск и правка текста. Всё остальное — веб, загрузки, подагенты — блокируется до выполнения.

👁️

Код игры — только чтение

Исходники Unity-проекта не входят в области записи. Изменить код агент не может ни при каких условиях.

🔒

Песочница по путям

В канале агент пишет только в общую базу, в личной сессии — ещё в папку владельца. Чужие личные папки для него не существуют.

↩️

Всё обратимо

Каждый ход агента — git-коммит только тронутых файлов. Diff виден прямо в чате, откат — одна кнопка.

🏠

Всё в периметре студии

Свой сервер, своя база, свои файлы. Одни и те же правила доступа для людей и для агента — из единого места в коде.

Под капотом

Просто разворачивается. Просто живёт.

Один start.batСам ставит окружение, заводит админа и базу. Ни Docker, ни внешних сервисов.
LAN и интернетРаботает в офисной сети и снаружи за реверс-прокси — один и тот же код, без настройки.
Фронтенд без сборкиЧистый JS, ноль npm и CDN. Ничего не тянется со сторонних серверов.
Живой стримингОтвет агента идёт настоящим потоком и проходит через любые корпоративные прокси.
SQLite + gitВся база — один файл, вся история доков — обычный git-репозиторий. Бэкап = копирование папки.
Тёмная и светлая темыВид «серьёзного ПО»: единая палитра токенов, без вспышек при загрузке.
Потенциал

Куда это растёт

Продукт уже в работе у команды — и это только основа. Ближайшие планы лежат на доске проекта, а горизонт — заметно дальше.

Видение
🔍

Агент-ревьюер диздоков

Сам сверяет документы с кодом и друг с другом: находит устаревшие цифры, противоречия между механиками и дыры в описаниях — раньше, чем их найдёт плейтест.

📰

Дайджест изменений

Еженедельная сводка: что поменялось в коде игры и какие диздоки пора обновить. Понедельник начинается с одного сообщения агента, а не с раскопок.

📊

Баланс-таблицы из кода

Агент собирает актуальные цифры баланса прямо из данных игры в живые таблицы волта — цифры в доках перестают устаревать в принципе.

🎮

Ассистент в Unity

Окно агента прямо в редакторе: выделил объект на сцене — получил его описание из волта и связанные механики, не выходя из движка.

🤖

Команда агентов

Специализированные роли: балансировщик, нарративщик, аналитик плейтестов. Каждый со своим набором прав и своей зоной волта.

🗺️

Аналитика базы знаний

Карта покрытия: какие механики игры описаны, какие доки мертвы, куда никто не ссылается. Здоровье документации — на одном экране.
