Знания команды не должны жить в головах

Документы разбросаны по гуглодокам, ответы «как это на самом деле работает» ждут свободного программиста, а решения из чатов теряются за неделю.

Было
  • Документы в разных сервисах, версии — «финал_2_новый»
  • «Как работает пена?» — вопрос программисту и день ожидания
  • Правки документов не отследить: кто, что, когда
  • Обсуждения в мессенджере отдельно от документов
Стало
  • Одна база знаний под git — каждая правка это коммит
  • Агент отвечает по исходникам проекта за минуту, со ссылкой на файл
  • Diff любого изменения и откат одной кнопкой
  • Чаты, документы и агент — в одном окне, со сквозным поиском
Что внутри

Три продукта в одном

Чаты команды

Каналы, личные сообщения, треды, реакции, закрепы, прочитанность — полноценный рабочий мессенджер уровня Slack, но на вашем сервере.

База знаний

База знаний в markdown под git: вики-ссылки, обратные ссылки, история правок, редактор в браузере, импорт и экспорт Word-файлов.

ИИ-агент

Ведёт документы и отвечает, как всё реально устроено в коде проекта. Каждый его ход — git-коммит с diff и кнопкой отката.

Чаты

Мессенджер, в котором ничего не теряется

Всё, к чему команда привыкла в Slack и Telegram, — и всё это связано с базой знаний.

  • Треды и ответы — любую ветку ответов можно свернуть в тред одной кнопкой
  • Прочитанность — галочки и «кто прочитал и во сколько»
  • Скриншот из буфера — Ctrl+V, и картинка уже в чате
  • Документ из волта — прикрепляется ссылкой, открывается рядом
  • Поиск Ctrl+K — сразу по сообщениям и документам
  • Реакции, закрепы, упоминания, черновики, «кто печатает», уведомления

Агент

Сотрудник, который читает код
и пишет документы

Агент знает ваш проект: профиль команды, договорённости, структуру кода. Ведёт базу знаний и отвечает на вопросы по исходникам — в реальном времени, у всех на глазах. Модель на выбор: Claude по подписке или любой OpenAI-совместимый API.

Стриминг

Ответ печатается по мере генерации, видно каждый инструмент. Команда наблюдает ход агента вживую.

В любом чате

Личные сессии — сколько угодно, с автоназванием. В каналах зовётся через @агент и видит контекст разговора.

Ничего не забывает

Сессии переживают перезапуск сервера. Занят — сообщения встают в очередь; любой ход можно остановить.

Код проекта

«Как это работает?» — ответ за минуту, а не за день

Агент читает исходники проекта и переводит их с языка кода на язык команды. На примере — игровая студия, но репозиторий может быть любым.

  • Пишет для людей — без имён классов и технических деталей, только суть и цифры
  • Всегда указывает источник — одна строка с путём к файлу
  • Читает зеркало рабочей ветки — не мешает программистам и не видит их недоделанных правок
  • Начинает с карты проекта — не бродит по репозиторию вслепую
  • Только чтение — изменить код проекта агент не может физически

Волт

База знаний, у которой есть память

Каждое сохранение — git-коммит с автором. История любого документа, diff любой правки, откат чего угодно.

  • Вики-ссылки — документы ссылаются друг на друга через [[название]], снизу видно, кто ссылается на этот док
  • Редактор в браузере — подсветка markdown, Ctrl+S, защита от затирания чужих правок
  • Word туда и обратно — импорт .docx с картинками, экспорт любого дока в .docx
  • Права — общая база для всех, личные папки видит только владелец
  • Поиск — по названиям и тексту, вместе с сообщениями чатов

Контроль

ИИ на коротком поводке

Агент полезен ровно настолько, насколько ему можно доверять. Поэтому каждое его действие ограничено технически, а не «честным словом».

Без доступа к системе

Выполнять команды агент не может вообще: shell запрещён целиком, git-коммиты делает сам сервер.

Белый список инструментов

Разрешено только чтение, поиск и правка текста. Всё остальное — веб, загрузки, подагенты — блокируется до выполнения.

Код проекта — только чтение

Исходники проекта не входят в области записи. Изменить код агент не может ни при каких условиях.

Песочница по путям

В канале агент пишет только в общую базу, в личной сессии — ещё в папку владельца. Чужие личные папки для него не существуют.

Всё обратимо

Каждый ход агента — git-коммит только тронутых файлов. Diff виден прямо в чате, откат — одна кнопка.

Всё на вашем сервере

Свой сервер, своя база, свои файлы. Одни и те же правила доступа для людей и для агента — из единого места в коде.

Под капотом

Просто разворачивается. Просто живёт.

Потенциал

Куда это растёт

Продукт уже в работе у команды — и это только основа. Ближайшие планы лежат на доске проекта, а горизонт — заметно дальше.

Видение

Агент-ревьюер документов

Сам сверяет документы с кодом и друг с другом: находит устаревшие цифры, противоречия и дыры в описаниях — раньше, чем на них наткнётся команда.

Дайджест изменений

Еженедельная сводка: что поменялось в коде проекта и какие документы пора обновить. Понедельник начинается с одного сообщения агента, а не с раскопок.

Живые таблицы из кода

Агент собирает актуальные цифры и настройки прямо из данных проекта в таблицы базы знаний — цифры в доках перестают устаревать в принципе.

Ассистент в редакторе

Окно агента прямо в рабочем инструменте — игровом движке или IDE: выделил объект — получил его описание из базы знаний, не переключая окно.

Команда агентов

Специализированные роли под ваш процесс: ревьюер, аналитик, редактор. Каждый со своим набором прав и своей зоной базы знаний.

Аналитика базы знаний

Карта покрытия: что в проекте описано, какие доки мертвы, куда никто не ссылается. Здоровье документации — на одном экране.
