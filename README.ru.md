# Foreman

**[English](README.md) | Русский**

Self-hosted рабочее пространство для небольшой команды: чаты, база знаний под
git, канбан-доска, созвоны с расшифровкой — и ИИ-агент, который ведёт ваши
документы и отвечает на вопросы, читая исходники проекта по-настоящему.

Всё живёт на вашем сервере. Одна SQLite-база, один git-репозиторий документов,
фронтенд без сборки и без единого обращения к CDN.

## Что внутри

- **Чаты команды** — каналы, личные сообщения, треды, реакции, закрепы,
  прочитанность, упоминания, вложения, скриншот из буфера по Ctrl+V.
- **База знаний («волт»)** — markdown-документы под git: вики-ссылки, обратные
  ссылки, редактор в браузере (WYSIWYG или CodeMirror), полная история,
  откат одной кнопкой, импорт и экспорт Word.
- **ИИ-агент** — живёт прямо в чате. Ведёт волт, отвечает «как это на самом
  деле работает», читая зеркало кодовой базы (только чтение). Каждый его ход —
  git-коммит с видимым diff и кнопкой отката.
- **Канбан-доска** — задачи с drag & drop, чеклистами, приоритетами и метками;
  агент тоже умеет её читать и обновлять.
- **Созвоны** — голосовые звонки WebRTC с демонстрацией экрана; дорожка
  каждого участника пишется и может расшифровываться в тред внешним
  ASR-пайплайном.

## Движки агента

Два взаимозаменяемых способа, выбираются на чат в админке («Модели агента»):

| Движок | Что нужно |
|---|---|
| **Claude** (Agent SDK) | Подписка Claude: Node.js + [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code), затем `claude setup-token` → вывод в файл `auth_token.txt` |
| **OpenAI-совместимый** | Любой эндпоинт: OpenRouter, локальный LLM-сервер и т.п. Базовый URL + ключ в админке |

Без обоих сервер тоже работает — остаются чаты, волт и канбан.

## Быстрый старт

Требования: **Python 3.10+** и **git** в `PATH`.

```bash
git clone https://github.com/DanilShekarev/foreman.git
cd foreman
./start.sh        # Windows: start.bat
```

Первый запуск создаст venv, поставит зависимости, засеет базу и напечатает
пароль админа в консоль. Откройте http://127.0.0.1:8010 и войдите как `admin`.

Все настройки необязательны и живут в `.env` (скопируйте `.env.example`).

## Подключение кодовой базы

Укажите любой локальный git-репозиторий:

```ini
# .env
GD_CODE_REPO=D:\путь\к\проекту
GD_CODE_PATHS=src;docs        # опционально: ограничить выкачку подпапками
```

Агент никогда не видит рабочую копию. Foreman держит мелкое частичное
**зеркало** ветки (`GD_CODE_BRANCH`, по умолчанию `main`): только
закоммиченное, обновляется раз в `GD_MIRROR_SYNC_MIN` минут. Чтобы зеркало
не распухало, включите в *исходном* репозитории две локальные опции:

```bash
git config uploadpack.allowFilter true
git config uploadpack.allowAnySHA1InWant true
```

Затем заполните два документа в корне волта (при первом запуске сеются
шаблоны): `PROJECT.md` — чем занимается команда, своими словами;
`CODE_MAP.md` — карта репозитория. Оба агент читает в начале каждого
разговора, правятся они прямо в веб-интерфейсе.

## Агент на коротком поводке

Права агента ограничены технически, а не вежливостью промпта:

- **Без shell.** Bash запрещён целиком; git-коммиты делает сервер, а не агент.
- **Белый список инструментов.** Только чтение, поиск и правка текста —
  ни веба, ни загрузок, ни подагентов.
- **Песочница по путям.** Запись: общая папка волта (в личной сессии — плюс
  папка владельца). Зеркало кода: только чтение. Все правила путей — в одном
  модуле (`vaultlib.py`), общем для гардов агента, HTTP API и UI.
- **Всё обратимо.** Каждый ход коммитит только тронутые файлы; diff виден
  в чате, откат — одна кнопка.

## Необязательные интеграции

- **pandoc** — включает экспорт документов волта в `.docx`.
- **Расшифровка созвонов** — каталог внешнего ASR-пайплайна
  (`GD_TRANSCRIBE_DIR`); нет каталога — звонки работают, расшифровка тихо
  выключена.
- **TURN-сервер** — для звонков через строгие NAT (`GD_TURN_URL` и т.д.);
  без него звонки работают в LAN и простых сетях. Звонкам нужен HTTPS
  (обратный прокси, например Caddy) — на голом http кнопка звонка скрыта.

## Справочник настроек

Полный список — в [.env.example](.env.example), там задокументирована каждая
переменная. Главное:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `GD_HOST` / `GD_PORT` | `127.0.0.1` / `8010` | Адрес прослушки |
| `GD_WEB_BASE` | — | Префикс пути за обратным прокси |
| `GD_ADMIN_PASSWORD` | случайный, печатается раз | Пароль админа при первом запуске |
| `GD_DB` / `GD_VAULT` | `data/gd.sqlite` / `vault/` | Где лежат данные |
| `GD_CODE_REPO` | — | Git-репозиторий для чтения агентом (пусто = без кода) |
| `GD_CLAUDE_TOKEN_FILE` | `auth_token.txt` | Токен подписки Claude |

## Архитектура одним абзацем

FastAPI + SQLite (WAL) + ванильный JS. Один воркер uvicorn, без reload —
агент-сессии живут в процессе. Стриминг агента — NDJSON поверх POST, остальные
клиенты поллят ленту изменений. Волт — отдельный git-репозиторий, все записи —
под одним локом. Единственный WebSocket — сигналинг звонков, медиа ходит
peer-to-peer. Подробный разбор — в [AGENTS.md](AGENTS.md): файл писался как
контекст для ИИ-агентов, но людям он полезен не меньше.
